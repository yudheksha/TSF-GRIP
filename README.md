# TSF-GRIP Internship (2021) — Data Analytics Projects

This repo contains projects completed during **The Sparks Foundation (TSF) — GRIP Internship (2021)**.

---

## 1) COVID-19 Analytical Dashboard (Power BI)

Built an interactive **Power BI dashboard** to analyze global COVID-19 trends and compare impact across countries and time.

Dataset:
- Scraped from **worldometers.info** (obtained by **Joseph Assaker**, scraped on **May 14, 2022**)
- **225 countries**
- Date range: **Jan 22, 2020 – May 14, 2022**

Dashboard highlights:
- Daily and cumulative **confirmed cases, deaths, recoveries**
- **Top 5** most impacted countries on a selected date
- Interactive **maps and charts** to explore spread by country/region
- Country-level view for detailed exploration
- **Top 10** most impacted countries for a selected month

How to run:
- Open the `.pbix` file using **Power BI Desktop**

## 2) Exploratory Data Analysis — Global Terrorism (Python)

Performed **EDA** on the **Global Terrorism** dataset to identify terrorism hot zones and extract security-focused insights.

Key focus:
- Identify **hot zones** by region/country
- Trend analysis over time (year/month patterns)
- Breakdown by **attack type, target type, weapon type**
- Severity insights using **fatalities/injuries** (where available)

Tools:
- Python (Pandas, NumPy, Matplotlib) in Jupyter Notebook
